# ATX 智能体助手

**让 DeepSeek Harness 在聊天中使用 ATX 搜索网页、生成图片、识别图片。**

这是 ATX 官方插件，适用于 **DeepSeek Harness 桌面应用（DSH 0.2.2-rc.3）**，不是给 DeepSeek 网页版或手机 App 安装的插件。

## 第一步：下载并安装

### 方法 A：让智能体帮你安装（更省事）

在 **DSH 聊天窗口**发送下面这句话：

> 请安装 ATX 官方插件，仓库地址是 https://github.com/aitransx/atx-deepseek-plugin 。安装完成后检查 ATX 状态，不要发起收费测试。

如果弹出安装确认，核对仓库是 `aitransx/atx-deepseek-plugin` 后允许。如果当前模式没有插件管理工具，使用下面的方法 B。

### 方法 B：自己下载 ZIP 安装

1. **[点击下载最新版 ATX-assistant.zip](https://github.com/aitransx/atx-deepseek-plugin/releases/latest/download/ATX-assistant.zip)**。
2. 将 ZIP **解压**到准备长期保留的位置。不能直接选择压缩包内的文件。
3. 在 DSH 打开 **插件 → 添加插件**，选择解压后的 `aitransx-assistant` 文件夹。这个文件夹内应直接能看到 `package.json`。
4. 按应用提示完成安装。如果提示重启，先重启 DSH。
5. 新开一个聊天，发送：**检查 ATX 状态**。

安装后不要删除或移动插件文件夹。本插件无需手动安装 Node.js 或运行代码。

> 下载提示：请下载上面的 **ATX-assistant.zip**，不要选发布页底部自动生成的 “Source code (zip)”。如果 GitHub 下载失败，可换网络后重试。

## 第二步：确认 ATX 账号已经连接

**安装插件不等于拥有 ATX 账号、API Key 或免费额度。** 搜索、生图和识图会使用你的 ATX 账户，可能收费。

### 你已经在 DSH 配置过 ATX 模型

通常不用再填 Key。插件会尝试复用现有 ATX 服务商配置。发送：

> 检查 ATX 状态，告诉我是否已经连接账号，默认识图和生图模型分别是什么。不要发起收费测试。

- 显示 `credentialConfigured: true`：已找到凭据，可继续第三步；这还不代表余额及全部模型权限已验证。
- 显示 `false` 或连接诊断：先不要重复填 Key，也不要反复生成图片。发送：

> 查看可关联的 ATX 服务商，帮我检查为什么没有连接。不要读取或展示密钥。

如果列出多个服务商，确认你要使用哪一个，再让智能体关联它。

### 你还没有在 DSH 配置 ATX

1. 到 [ATX 控制台](https://aitransx.com/zh/login)创建或取得 API Key，确认余额与使用权限。
2. 先在 DSH 的**模型设置**中添加 ATX 服务商：OpenAI 兼容接口，地址填 `https://api.aitransx.com/v1`，在应用提供的密钥输入框保存 Key。
3. 完成服务商配置后重新加载插件或重启 DSH，再发送 **检查 ATX 状态**。
4. **看到 `credentialConfigured: true` 再继续。** 如果仍为 false，发送：「查看 ATX 服务商关联与凭据引用，解释缺少哪一项；不要读取或展示密钥。」保存 Key 不一定代表插件已正确关联。

不同 DSH 版本的配置入口可能不同。如果找不到密钥输入框，请向维护者提供设置页面截图（遮住 Key）。**不要把 Key 发到聊天、GitHub Issue 或公开截图中。**

当前仅自动复用已有服务商的 `apiKeyEnv` 凭据引用；OAuth 或仅自定义 Authorization header 的配置暂不支持。高级用户也可通过 DSH 凭据系统提供名为 `AITRANSX_API_KEY` 的凭据。

## 第三步：直接在聊天里使用

**不用记工具名，不用写代码，也不用切换当前聊天模型。** 你的聊天模型需能正常调用 DSH 工具。

第一次可以只选下面一个例子发送。这会真实调用 ATX，可能收费，不是免费演示。搜索成功应看到结果与来源；生图成功应看到图片／链接或明确的附件状态；识图成功应看到对指定图片的描述或文字结果。

### 联网搜索

复制发送：

> 用 ATX 搜索最近一周 AI 行业的三条重要消息，简要总结并附来源链接。

想读某个网页：

> 用 ATX 读取 https://aitransx.com/zh/docs ，总结主要接口。

### 生成图片

复制发送：

> 用 ATX 生成一张图片：秋天的公园里，一位穿红色外套的成年女性站在金色树下，温暖光线，精致动漫插画。生成一张即可。

默认使用 `openai/gpt-image-2`。成功后通常会返回图片或可打开的文件链接；如果提示已生成但没有可打开路径，请保留附件信息并求助，不要重新生成。

只想这次换型号：

> 这次用 ATX 的 openai/gpt-image-2.5-flash 生成一张蓝色陶瓷杯的产品图。

**调用失败或超时后，先查看 ATX 请求记录，不要立即重复生成：上游可能已经处理并计费。** 插件不会自动换模型重试。

### 识别图片／提取文字

目前最稳妥的是给出**图片文件路径**，不是直接把图片上传给不支持视觉的聊天模型。

1. 在 Windows 文件资源管理器里找到图片，右键选择 **复制文件地址**（部分系统需按住 Shift 再右键）。
2. 在聊天中输入「用 ATX 识别这张图片：」，粘贴地址，再写问题。例如：

```text
用 ATX 识别这张图片："C:\\Pictures\\screenshot.png"，提取所有可见文字，并解释其中的报错。
```

上面的路径只是示例，必须替换成你复制的实际图片地址。公开 HTTPS 图片链接也可以。如果图片已放在当前会话工作目录中，也可以只写 `screenshot.png`；不确定工作目录时优先用完整路径。

默认识图模型是 `openai/gpt-6.1-terra`。本地图片支持 PNG、JPEG、WebP，每张最多 4 MiB，一次最多 4 张；图片会发送给 ATX。

> 重要：如果你直接上传图片，而聊天主模型在工具运行前就拒绝图片，插件无法拦截。改用文件路径或公开链接即可。插件也不会自动上传你没有指定的图片。

## 换模型：直接说，不用编辑文件

| 你想做什么 | 在 DSH 聊天中发送 |
| --- | --- |
| 查看现有模型 | 查看 ATX 模型，先列出支持识图和生图的型号。 |
| 刷新型号列表 | 刷新 ATX 模型列表，不要做收费测试。 |
| 改默认生图模型 | 把 ATX 默认生图模型设为 openai/gpt-image-2.5-flash。 |
| 改默认识图模型 | 把 ATX 默认识图模型设为 openai/gpt-6.1-terra。 |
| 添加新型号能力 | 我确认“完整模型 ID”支持生图，请加入 ATX 能力表。 |
| 关闭定期检查 | 关闭 ATX 模型目录的自动刷新。 |

预置：`openai/gpt-6.1-terra` 用于识图；`openai/gpt-image-2`、`openai/gpt-image-2.5-flash` 用于生图。模型可用性和费用以 ATX 当前账户为准。

默认在 DSH 运行期间每 24 小时更新一次目录，也可手动刷新。**新型号不会自动获得生图／识图权限，也不会取代默认型号。** 配置变更影响当前配置档内所有会话。

## 遇到问题怎么办？

| 现象 | 下一步 |
| --- | --- |
| 智能体说找不到 ATX 工具 | 检查插件是否启用；按提示重启 DSH，再新建聊天。 |
| 提示没有 API Key | 回到第二步检查服务商关联；不要把 Key 发给智能体。 |
| 提示模型不存在／不支持 | 刷新模型列表，核对完整 API ID 与能力表，不要只填显示名称。 |
| 图片上传后主模型报错 | 将图片保存到本地，改为发送文件路径。 |
| 余额／权限错误 | 到 ATX 控制台检查余额、Key 权限和模型可用性。 |
| 超时、网络失败 | 先核对 ATX 请求日志，确认费用和状态，再决定是否重试。 |

还没解决？在 [GitHub Issues](https://github.com/aitransx/atx-deepseek-plugin/issues) 提交：DSH 版本、插件版本、做了什么、完整报错或脱敏截图。**遮住 API Key、个人路径中的用户名和不想公开的图片。**

## 更新插件

[下载新版 ZIP](https://github.com/aitransx/atx-deepseek-plugin/releases/latest/download/ATX-assistant.zip) → 备份自定义设置 → 按 DSH 插件管理提示移除旧安装、添加新版解压目录。当前不提供静默自动升级；**模型列表自动更新不等于插件程序自动更新**。

## 当前版本与限制

版本 **0.2.1**，适配 DSH **0.2.2-rc.3**。没有单独的图形设置页，配置以聊天为主。生图只取第一张，不保证所有型号支持参考图、GIF 或所有尺寸。当前版本不修复 Gemini 工具调用协议兼容问题。
